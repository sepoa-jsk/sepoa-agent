## 주의

- 견적 3건은 **DB에 남겨둔다**(고객사명 뒤 `[기준선]` 표기). 이후 STEP 의 대조 기준이므로 삭제하지 않는다.
- 견적번호는 채번 순서에 따라 재생성 시 달라진다. **금액·블록소계·레이아웃**으로 대조한다.
- PDF 는 생성 시각·견적번호가 달라 바이트 단위 비교가 불가하다. 페이지 수와 금액, 레이아웃 육안 대조로 판정한다.
