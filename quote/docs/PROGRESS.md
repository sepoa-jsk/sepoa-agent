### 운영 DB 백업 — 미완 상태로 작업 1 진행함 (2026-08-01)

작업 1은 **비파괴**(브랜치 생성 · 테스트 실행 · 스키마 조회 · 행수 집계)라 백업 없이 진행했다.
DB 변경은 기준선 견적 3건 **추가**뿐이며 기존 데이터는 건드리지 않았다.

작업 1이 남긴 것은 백업이 **아니다**:

| 산출물 | 내용 | 백업 대체 가능 여부 |
|---|---|---|
| `baseline-schema.sql` | 구조(DDL)만 | 불가 — 데이터 없음 |
| `baseline-rowcount.md` | 행 수만 | 불가 — 값 없음 |

**작업 20(레거시 정리)은 `sq_labor_rates`(6행) · `sq_quote_sections`(15행) · `sq_nego_rates`(20행)을
실제로 DROP 하므로, 그 전에 반드시 데이터 포함 백업이 필요하다.**
작업 10·13·18 진입 전에도 백업 태그를 권장한다(WBS §7).
