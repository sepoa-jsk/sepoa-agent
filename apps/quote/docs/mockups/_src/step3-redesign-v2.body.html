참고한 제품들의 공통 구조 (Salesforce CPQ · DealHub · PandaDoc · HubSpot)

  • 구성 질문(Guided selling) — 영업이 몇 가지 질문에 답하면 맞는 품목 · 수량 · 가격이 규칙대로 채워진다. 표를 직접 만지는 일이 줄어든다.
  • 라인 편집기 한 장 — 품목은 블록(그룹)별로 묶은 표 하나에서 고친다. 그룹 머리에 소계, 위에는 견적 전체에 걸리는 값.
  • 정가 → 제안가 → 할인율을 한 줄에서 보인다 — 네고(차수)할 때 무엇을 얼마나 깎았는지가 바로 보인다.
  • 늘 보이는 요약과 확인 목록 — 합계와 "보내기 전에 확인할 것"(가드레일)을 옆에 고정.
  • 문서 부분은 따로 — 결제 조건 · 약관 같은 문서 문구는 라인과 섞지 않고 접힌 요약으로, 미리보기에서 완성본을 본다.

이 안에서 바꾼 점 (번호)

  1. 구성 질문 카드 새 기능 제안 — 서비스 · 인원/건수 · 독립인프라 · 내부 연계를 고르면 아래 라인이 채워진다(지금은 템플릿 + 직접 입력).
  2. 표 하나에 블록을 묶음 행으로 — 블록마다 따로 있던 표 머리 · 버튼 줄이 하나로 줄어든다. 묶음 행은 접을 수 있다(▾ 누르기).
  3. 할인율 칸 새 칸 제안 — 기준단가 대비 제안단가. 네고 차수에서 얼마 깎았는지 보인다(계산만, 입력 없음).
  4. 결제 방안 · 견적조건은 접힌 요약 줄 — 누르면 펼쳐서 고친다. 라인 편집과 문서 문구를 나눈다.
  5. 오른쪽 견적 요약(읽기만) — 일시불 · 월 금액, 차수, 가격정책 버전. 지난번 뺀 합계 표(DC · 절사 입력)는 되살리지 않았다.
  6. 확인 필요 목록 새 기능 제안 — 금액 없는 행, 견적용도 빈칸처럼 발행 전에 볼 것을 모아 보인다.
